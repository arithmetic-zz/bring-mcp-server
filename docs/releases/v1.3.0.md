# v1.3.0 — Reliable item lookup and batch changes

Resolves issues #7–#19.

- Match existing items using their base or composed display name, with case, whitespace and German spelling normalization as a fallback. Ambiguity errors include candidate UUIDs.
- Preserve omitted specifications; document explicit replacement and clearing. Add `on_exists=skip` and `error` alongside the default upsert.
- Reject invalid UUIDs when creating items and prevent name-only completion of unknown or history-only items.
- Filter `get_list` with `filter` or `query`, including UUID and section status in JSON lookup results.
- Accept case-insensitive string booleans for `include_recent`; report tool and field in validation errors and reject unknown parameters.
- Support snake_case and legacy batch aliases, including `specification`. Accept read-only `attributes` from list JSON without sending them as write attributes.
- Preflight every batch target before writing. Return per-item UUIDs and created/updated/removed/completed status in JSON text and MCP structured content.

Batch preflight cannot prevent races with other Bring clients. Tests use mocked Bring access; standalone smoke tests verify offline MCP startup and protocol behavior.

Downloads are built for Linux x86_64, Windows x86_64, macOS arm64 and macOS x86_64. Archives and SHA256SUMS are published only after all target builds, source tests and archive smoke tests pass.
