## Second independent review requested by the user

A new reviewer re-ran all 65 tests and independently reproduced a P2 gap: real Bring item attributes with `activeFrom`/`activeTo` parse into datetime objects, which the JSON serializer rejected. A new in-memory MCP regression test failed before the fix. Recursive boundary conversion now preserves these values as ISO 8601 strings. The test verifies tool JSON and resource JSON with the real Bring response parser.

The corrected full source suite passes all 66 tests. The second reviewer independently verified the fix, naive timestamps and non-UTC offsets, nested containers, and unchanged False/None values; no remaining actionable findings. A localized/canonical-name edge was also investigated: matching uses the exact localized names returned by `get_list`; this is documented, with UUID selection advised for other spellings/languages.
